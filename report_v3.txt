## SECTION 1 — Explaining the Linter Findings

### Line 1: `import os,sys`
- **E401 (multiple imports on one line)** and **E231 (missing whitespace after ',')**
- PEP 8 says imports should usually be on separate lines. Even though the excerpt provided doesn't cover E401 directly, PEP 8's general import guidance is: one import per line makes it easy to see what's being added/removed in version control and easy to read at a glance.
- E231 is about the comma: PEP 8's whitespace rules require a space after commas (just like you'd write `os, sys`), the same logic that requires whitespace after commas in function calls like `spam(ham, eggs)`.
- **Fix:**
  ```python
  import os
  import sys
  ```
