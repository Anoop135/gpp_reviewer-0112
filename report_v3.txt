# SECTION 1 — Linter Findings Explained

**Line 1: `import os,sys`**
- **E401 (multiple imports on one line)** — PEP 8 says each import should generally be on its own line. Better:
  ```python
  import os
  import sys
  ```
- **E231 (missing whitespace after ',')** — Should be `import os, sys` if you were combining them, but since E401 says not to combine them anyway, this becomes moot once you split the imports.

**Line 2: `def CalculateTotal( items ):`**
- **E302 (expected 2 blank lines, found 0)** — PEP 8 requires top-level function/class definitions to be separated by two blank lines. There's no blank line before this function.
- **E201 (whitespace after '(')** and **E202 (whitespace before ')')** — PEP 8's "Pet Peeves" section says: *"Avoid extraneous whitespace... immediately inside parentheses, brackets or braces."* So `( items )` should be `(items)`.

**Line 3: `Total=0`**
- **E225 (missing whitespace around operator)** — PEP 8 says binary operators like `=` should have consistent spacing: `i = i + 1` is correct style, so this should be `Total = 0`.

**Line 8: `class shopping_cart:`**
- **E302** — Same rule as before: two blank lines are needed before a class definition. Only one blank line exists here.

**Line 9: `def __init__(self,name):`**
- **E231 (missing whitespace after ',')** — Should be `def __init__(self, name):`. Commas need a space after them for readability.

**Line 10: `self.name=name`**
- **E225** — Same as before: needs spaces around `=`. Should be `self.name = name`.

**Line 12: `def add( self,item ):`**
- **E301 (expected 1 blank line, found 0)** — Methods inside a class should be separated by one blank line each; there isn't one before `add`.
- **E201 / E202** — Same whitespace-inside-parentheses issue as before: `( self,item )` → `(self, item)`.
- **E231** — Missing space after comma again: `self,item` → `self, item`.

**Line 15: after class definition**
- **E305 (expected 2 blank lines after class or function definition)** — Once you finish defining a class/function, top-level code (like `c = shopping_cart(...)`) needs two blank lines of separation.

**Line 18: `print( CalculateTotal(c.x) )`**
- **E201 / E202** — Same "no space right inside parentheses" issue: `( CalculateTotal(c.x) )` → `print(CalculateTotal(c.x))`.
- **W292 (no newline at end of file)** — Every file should end with a newline character. Your last line doesn't have one — just press Enter after the last line before saving.

# SECTION 2 — Issues the Linter Won't Catch

1. **Naming conventions (PEP 8):**
   - `CalculateTotal` should be `calculate_total` — PEP 8 specifies functions and variables should use **snake_case**, not **CamelCase** (CamelCase is reserved for class names).
   - `Total` (inside the function) should be lowercase: `total`. Same snake_case rule applies to local variables.
   - `shopping_cart` — this is actually good spelling but classes should use **CapWords/PascalCase**, so it should be `ShoppingCart`, not `shopping_cart`.
   - `self.x` is a poor variable name — it gives no indication of what it stores. Since it holds cart items, something like `self.items` would be far more descriptive.
